NIST's OSCAL 1.2.1 JSON schemas for the System Security Plan and POA&M models, used by `tests/exports.py` to
validate what Preflight exports. NIST publishes these with each OSCAL release (https://github.com/usnistgov/OSCAL);
these copies come from the `release-schemas` folder of compliance-trestle. NIST works are public domain.
